Poisson's ratio (ν)0.42
Muscle anisotropy info Muscle behaves differently depending on how it's deformed relative to the fiber direction:

Case 1 — Isotropic (single value, same in all directions): ν = 0.47–0.49. This is how every other tissue in this simulation is modeled (liver, skin, fat, kidney, spleen) — one number describes the whole tissue regardless of push direction.

Case 2 — Anisotropic (real muscle, direction-dependent): ν = 0.28–0.74, made up of three distinct values depending on direction:
  • longitudinal-transverse ≈ 0.47
  • transverse-transverse ≈ 0.28
  • transverse-longitudinal ≈ 0.74
This reflects muscle fibers running in one dominant direction — squeezing along the fiber behaves differently than squeezing across it.

This simulation uses Case 2 (0.28–0.74) as the actual slider range for Muscle, with default ν = 0.47 (the longitudinal-transverse value).
